# Natally voice-conditioning references

These are synthetic PCM reference clips generated from the existing Natally
Supertonic presets F1-F5/M1-M2 at natural rate/pitch, then resampled to 24 kHz.
They let the replacement engine retain the existing voice selector and saved IDs.
The application does not run Supertonic to use these clips and includes no model
weights here. Chatterbox conditioning does not promise identical voice identity.

Source: onnx-community/Supertonic-TTS-ONNX,
revision cff123c84b0655d9d647641f1b532c3cbb8f7faa (Supertone; OpenRAIL license).
Text: the fixed public Natally voice-check passage. No user recordings are used.

under its upstream MIT license. Model files are fetched by immutable revision.
